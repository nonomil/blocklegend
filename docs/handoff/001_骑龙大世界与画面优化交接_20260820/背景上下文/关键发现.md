# 关键发现（证据分层：✅已验证 / 🔮推测 / 🔲待验证）

## 发现 1：世界是"桌面模型"，撑不起骑龙视野 ✅

实测（2026-08-20）：
- `data/world-gen.js:10-11`：WORLD_SIZE=384、**HEIGHT_MAX=16**——全图高差 ≤16 格（≈两层楼），无山脉可言
- 飞行上限 46（engine.js updateMountPhysics）、云层 42——穿云即触顶
- 高度 40+ 时 384 边长的世界**一眼看到边缘**；雾远端 ~112 高空截断视野
- 结论：参考游戏"骑龙高广"的本质是**地形振幅大 + 大尺度地标**，不是地图无限大 → 见三阶段方案
