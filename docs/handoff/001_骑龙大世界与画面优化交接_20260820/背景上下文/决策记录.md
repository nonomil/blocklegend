# 决策记录（2026-08-20 会话）

| # | 决策 | 理由 | 代价/风险 |
|---|---|---|---|
| D1 | 模块化只拆**纯数据层**（world-gen），engine 闭包/game.js 不拆 | 用户选择 + BL-21 延后；闭包深耦合拆了破坏状态共享 | game.js 7490 行仍是单体（已知债） |
| D2 | 世界生成区(55-1779) 与体素查询区(2286-2671) **合并为一个文件**而非两个 | 实测双向耦合：createWorld 依赖 buildTreeCols/habitatOf/surfaceAtWorld；体素区依赖 hash3/biomeAt | 原计划"voxels.js 独立文件"取消 |
| D3 | mobs.js 不做 window→global 改造 | 浏览器内等价、无功能收益、30+ THREE 引用回归风险 | 风格不完全统一（接受） |
| D4 | 骑乘时 Q/E 归回旋，禁用 tryBolt/tryEat | 键冲突实锤；HUD 已提示 F 下龙 | 骑乘中无法用 Q 发魔法（合理：左键已有龙息） |
| D5 | 左键=龙息，**右键保留下龙** | HUD 原提示"F 或右键下来"，不破坏既有 UX | 与参考游戏"右键魔法"不同（骑乘态专属差异，接受） |
| D6 | 龙模型**不用 CliproxAPI 重做** | dragon-atlas 早已存在且已激活；API 当时双路不通 | 无（省一次生图成本） |
| D7 | 云层用 InstancedMesh、lite 模式不建 | 1 draw call 红线内 | 云无阴影/无体积（接受） |
| D8 | 世界改造分三阶段，**先拔高不扩图** | Phase 1 改动集中（rawHeight+3常量）可快速验证；扩图受 576 draw call 真机帧率约束 | Phase 3 暂缓可能永远不做（视验收） |
| D9 | 测试基线更新是正当的，不绕断言 | heights 锚会因振幅改动合法失效 | 每次地形改动都要人工核对测试期望 |
| D10 | API key 只从 cliprox.local.env 读，绝不落盘 | CliproxAPI 文档安全约束（其文档 :6 与 :121） | 无法在交接文档记录可用 key（本来也不该） |
