# 待做实验（验证类，带通过标准）

## E1. MuMu 真机帧率 — Phase 1 前后对比 🔲

- 方法：同 seed、同起飞点、骑龙巡飞固定路线 60s，记录稳态帧率（devtools 或 MuMu 帧率显示）
- 基线：Phase 1 之前先测一次（**当前还没测，做 Phase 1 前必须补**）
- 通过：劣化 ≤15%；超了 → 降振幅（±20→±14）或减云密度重测
- 注意：HEIGHT_MAX 48 后每区块三角形数上升，这是主要开销来源，不是 draw call

## E2. 同 seed 截图对比 🔲

- 方法：固定 seed=7，同一坐标（村庄上空 y=60 俯视 + 地面平视）Phase 1 前后截图并排
- 通过：山系带状可见、村庄平缓、单词门可达、无明显悬浮树/悬空建筑

## E3. 骑乘摔落伤害验证 🔲

- 方法：骑龙升至 60 格，F 下龙（或触顶），观察 HP 变化
- 通过标准待定：若当前有摔伤 → 骑乘/下龙瞬间给 2s 缓冲或伤害减半（孩子体验优先）；无摔伤 → 记录"已豁免"即可

## E4. 高空雾观感 🔲

- 方法：y=70 平视远方，对比 fogFar ×1.8 开/关
- 通过：能分辨远方山系轮廓而非白茫茫；不出现"雾开后看见世界边缘"的突兀（必要时配合远端地形 LOD/边缘高山）

## E5. 云层穿行观感 🔲

- 方法：骑龙在 y=72 云层高度平飞 + 从上往下穿云
- 通过：穿云有遮挡感但不全黑；云不与雾色冲突（nether/deep_dark 暗云下观感重点看）
