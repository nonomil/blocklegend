# 工具清单

## 命令速查（全部实测有效）

| 场景 | 命令 |
|---|---|
| 语法检查 | `node --check engine.js` / `game.js` / `data/*.js` |
| 跑测试 | `node --test "test/*.test.mjs"`（**glob 必需**，`test/` 不行） |
| 临时静态服务 | `cd G:\StudyCode\个人工作台; python -m http.server 8642 --bind 127.0.0.1` |
| 无头 Chrome | `chrome --headless=new --disable-gpu --remote-debugging-port=9642 --user-data-dir=<tmp> <url>` |
| CDP 页面列表 | `curl -s http://127.0.0.1:9642/json` |
| 端口排查 | `netstat -ano | findstr :4196` → taskkill /PID <pid> /F |
| 冒烟脚本 | `node bl-smoke.mjs "<page-ws-url>"`（见 测试分析报告.md 第四节） |

## 项目内既有工具

| 工具 | 位置 | 说明 |
|---|---|---|
| fourview 编译器 | `tools/fourview-to-atlas.py` | 四视图 → 图集+manifest（python） |
| fourview 模型工厂 | `assets/img2threejs/fourViewModel.js` | manifest → three.js 盒组 + 腿臂摆动/翅膀扇动 tick |
| 四视图验收页 | `compare-four-view.html` | 正交四向渲染 vs 参考图并排 |
| 程序化龙兜底 | `assets/img2threejs/createDragonModel.js` | fourview 缺失时的 fallback（前 10 行是激活分支） |
| 图集绘制 | `data/atlas-paint.js` | 纯数据零 DOM，node 可直接 import 测试 |

## 关键全局命名空间（IIFE 契约面）

| 全局 | 提供方 | 消费方 |
|---|---|---|
| `BlockLegendWorld` | data/world-gen.js（~69 导出） | engine.js（解构 + 再导出） |
| `BlockLegendEngine`（38 键） | engine.js | game.js（`ENG.*` 直读，名字逐字保留） |
| `BlockLegendMobs` | mobs.js | game.js（MOBS 别名，spawnBurst/skillShotMesh 等） |
| `BlockLegendAtlas4V` | assets/atlas4v/*-atlas.js | fourViewModel.js（dragon/villager 等 ~40 种） |
| `BlockLegendFourView` | assets/img2threejs/fourViewModel.js | createDragonModel.js 等模型工厂 |
| `BlockLegendAtlasPaint` | data/atlas-paint.js | atlas 测试 + makeBlockAtlas |
| `BlockLegendFx.climateMood` | fx（可选） | applySky 雾色覆盖 |

## 加载顺序（index.html，勿乱动）

```
atlas-paint.js → tools.js → data/world-gen.js → engine.js → combat → mobs → atlas4v(40+) → fourViewModel → game.js(boot)
```
（Combat 在 engine 后但只被运行时读取，主路径安全——勿提前加载除非改硬依赖）
