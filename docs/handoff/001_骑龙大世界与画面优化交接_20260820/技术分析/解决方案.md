## D. 本周期已实现方案的技术要点（接手者需知道的实现细节）

### 骑龙（engine.js updateMountPhysics:1091-1212）
- FLY=9.6 / CLIMB=6.8 / BOOST_X=1.7 / ROLL_DUR=1.5s
- boost：mount.speedFactor 平滑趋近（SMOOTH = min(1, dt*6)）
- roll：mount.rollState('rolling'→'done')/rollT/rollDir；rollAngle = dir * 2π * t；tickLife 消费 `mesh.rotation.z`
- 键映射在 engine.js refreshKeys:1302-1310（keys['r'/'q'/'e']），**不在 game.js**

### 龙息（game.js:1275-1298）
- beginMine 顶部 `if (engine.player.mounted && tryDragonBreath()) return;`
- 复用 fireBossShot：{shot:'fireball', track:!!aim, friendly:true, aimMob, dmg:4}
- 冷却 session.breathAt 1000ms；moveBossShots 命中走 hurtMonster(4)（HUD 伤害数字自动）
- 前向向量：`fx = -sin(look.yaw), fz = -cos(look.yaw)`（与 engine 一致）

### 急速尾迹（game.js tickRideTrail）
- 主循环 moveBossShots 后调用；speedFactor>1.25 且距上次 >90ms 时龙尾 spawnBurst(0xbfd8ff, 3)

### 云层（engine.js:699-741）
- InstancedMesh(BoxGeometry(CELL*0.72, 3, CELL*0.72))，CELL=14，rng=makeRng(seed^0x51cd)，密度 0.16
- makeScale+setPosition 组矩阵；frustumCulled=false；renderOrder=-500
- tickClouds 漂移 0.55 格/s，取模回绕；applySky 上色 light.cloud；lite 跳过

### Q/E 冲突修复（game.js:877-879）
