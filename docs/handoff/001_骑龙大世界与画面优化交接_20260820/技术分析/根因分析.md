# 根因分析

> 本周期主发内容是方案与实现，无生产缺陷排查。此处记录两类根因：①历史遗留问题的根因（已修）；②"子代理半成品"模式的根因。

## 1. Q/E 键冲突（已修 ✅）

- **现象**：骑乘时按 Q/E 触发回旋的同时误发追踪魔法/误吃东西
- **根因**：engine.js refreshKeys（:1308-1310）与 game.js keydown（:877-878）**两处独立绑定同一物理键**，无骑乘态协调——engine 侧子代理加映射时未检查 game.js 既有绑定
- **修复**：game.js 侧加 riding 守卫（engine 侧不动，键盘状态归 engine）
- **教训**：跨文件加按键绑定时，必须全仓 grep 该键的所有消费方

## 2. 龙息"实现了但没落盘"（已补 ✅）

- **现象**：骑龙物理子代理标记完成，但 game.js 无 tryDragonBreath
- **根因**：子代理死于 API 401（余额耗尽），其"完成"前最后动作是写代码途中；任务通知的 result 是截断的思考文本而非最终报告
- **教训**：子代理"completed/failed"通知不可当验收；**验收只认磁盘现状**（grep 目标符号 + node --check）

## 3. "氛围代理留了 cloud 色却没建云层"（已接 ✅）

- **根因**：同上 401 中断；代理按"先配数据后写功能"顺序工作，数据先落盘了
- **处置模式（可复用）**：盘点半成品时 grep"定义了但零引用"的配置/常量——它们是中断代理的"未完成清单"

## 4. 世界观感"平"的根因链（方案推导核心）

```
用户观感"骑龙不壮阔"
  ← 高空视野被雾截断(fogF~112)        → 修：高空雾扩展
  ← 一眼看到世界边缘(384 格)           → 修：Phase 3 扩图/无边感（暂缓）
  ← 地形无高差(HEIGHT_MAX=16)          → 修：Phase 1 脊谷噪声 ±20
  ← 无大尺度参照物                      → 修：Phase 2 大地标
```
其中地形高差是**主因**（其它三项都被它放大：没有山，高空看什么都是平的）。

## 5. "误报缺功能"的三次教训（方法论）

本周期三次报"缺 X"，实测都在——只是**搜错了文件**（R/Q/E 在 engine 不在 game；翅膀在 fourViewModel 不在 mobs；roll 消费在 tickLife 不在 game.js）。规则：多 IIFE 文件的项目里 grep"缺失功能"必须**全仓**（含 assets/、data/），并先 grep 消费端再下结论。
