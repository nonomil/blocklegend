## 1. 先分清三条完全不同的路

| 路 | 一句话生成的是什么 | 能不能当游戏用 | 对方块传奇 |
|---|---|---|---|
| **A. 世界模型** | 视频帧 / 高斯溅射 / 全景网格 | 能逛，不能当稳定玩法 | **不要接** |
| **B. 文生 3D 模型** | 一个有机网格（GLB/FBX） | 能当道具，不是方块 | **只能当参考，不能直接丢进引擎** |
| **C. 体素原生管线** | 16×16 贴图 + 盒模型 / schematic | 就是 MC 那种好看 | **这才是该走的** |

X 上的「成功案例」几乎全在 A。看起来炫，但世界会幻觉、没有稳定碰撞、没有词卡、没有存档。微软公开说过 Oasis **不是**官方 Minecraft。

这和参考 2 的告诫是同一类错误：把「Make a Minecraft clone」整段丢进已有仓库，会另起炉灶、冲掉词卡和 bridge。Oasis / Marble / Meshy 网格是另一种另起炉灶。

## 2. X 上确实有成功案例（成功在传播，不在可玩产品）

### 2.1 Oasis（2024-10-31，最大的一条）

- 原帖：[Etched 线程](https://threadreaderapp.com/thread/1852089772329869436.html)（`@Etched` × `@DecartAI`）
- 可玩演示：https://oasis.decart.ai
- 论文/站：https://oasis-model.github.io/
- 开源权重：[etched-ai/open-oasis](https://github.com/etched-ai/open-oasis) + Hugging Face `Etched/oasis-500m`
- 训练数据：OpenAI VPT（MIT）

X 上先火后嘲：`@wiiudisks` 一句 “Minecraft but with dementia” 几千赞；`@wiintahX` 放了「刚放下栅栏，一回头整栋楼自己长出来」的视频，约 1.3 万赞。技术成功，产品失败——没有物体持久性，360p–720p / 20fps，一次只能玩几分钟。

### 2.2 World Labs Marble（李飞飞，2025）

- 产品：https://www.worldlabs.ai/ · https://marble.worldlabs.ai
- 能力：一句话 / 一张图 → 可漫游、可导出的持久 3D 世界（高斯溅射 / mesh）
- 开源渲染：Spark，能接到 Three.js

好看、能逛、能导出。导出的是连续网格，不是可挖的方块。塞进方块传奇会立刻和现有 16³ 区块对不上。

### 2.3 谷歌 Genie 3

一句话生成可交互视频世界。同样是「下一帧预测」，不是引擎。

### 2.4 真正落到「我的世界里」的案例

籽岷等创作者常用路径（油管/X 都有，热度低于 Oasis）：

`一句话 → Tripo / Rodin 出网格 → objtoschematic.com → Litematica 蓝图`

这是「生成建筑」，不是「生成一款游戏」。

## 4. 提示词

### 4.1 参考 2 里的两档（编码模型，不是生图）

短提示（评测用，**禁止丢进本仓库**）：

```text
Make a Minecraft clone.
```

长提示（docsbot Browser Voxel Game）要求：Three.js、区块合批、挖放、准星描边、程序化小图集。你们已经有这一层。参考 2 原文见同夹 `DS-我的世界-3D-参考2.md`。

### 4.2 文生 3D（Meshy / Tripo / 混元）官方公式

```text
[一个主体], [真实材质], [风格], [技术约束]
```

Meshy 2026 指南要点：一次只生一个物体；3～6 个核心细节；写真实材质；角色加 `T-pose`；不要写 amazing/epic；排除项写进正文（没有单独负向框）。

### 4.3 Minecraft 方块风必须把几何锁死

否则会出圆润玩具 / 倒角 / PBR：

```text
vanilla Minecraft entity, only axis-aligned boxes,
16x16 pixel UV skin, nearest-neighbor, no bevel, no subdivision,
no subsurface scattering, no PBR gloss, flat lambert,
orthographic three-quarter, transparent background,
one subject, T-pose
```

地形块：

```text
Minecraft grass block, 16x16 pixel art,
green top, dirt sides with grass rim, dirt bottom,
faithful resource pack, no noise, no bevel
```

Meshy 有 Voxel 风格选项，但输出仍是网格，不是引擎要的 `BoxGeometry` 组。

**给方块传奇下一轮概念图，应改成上面这套，不要再要「高密度体素玩具」。**

## 5. 当前项目为什么还是不好看

不是缺「一句话生成」。缺口在三层错位。

### 5.1 地形：有图集，但是程序员噪声图集

`engine.js` 的 `makeBlockAtlas()`（约 L691）按 Fable5-mc `textures.js` 用 canvas 逐像素画 16px 噪声。参考 2 把「16×16 像素图集」列为让画面突然像 MC 的第 2 条；[优化分析](./优化分析-玩法与美术-20260816.md) §5 据此判「四件事均已实现」。

重判：**程序噪声图集 ≠ 手绘最近邻像素图集。** 前者把彩色盒子变成「有点像 MC 的演示」；后者才是 mcraft.fun 加载资源包之后的观感。草顶/草沿/泥底三张、石头噪点克制、`NearestFilter` 放大——结构已有，内容还是噪声。

### 5.2 生物：概念图和盒模型不是同一种画

已生成 roster（`prj/assets/generated/blocklegend-roster/raw/`）：

- `animals.png` / `golem.png` / `cubes-fox.png` / `village.png` / `bosses.png`

这些是「高级体素渲染图」：倒角、软光、羊身上很多小方块、铁傀儡有铆钉。好看，但不是原版 MC 实体。

引擎里的狐狸（`createFoxModel.js`）是 8×6×14 的几个盒子 + 16px 区域材质。参考图画完了，进游戏对不上，所以「参考图很精致，游戏还是丑」。

### 5.3 光和天

有顶点 AO，没有稳定的太阳方向、没有天空球（现在是 `scene.background` 平面图）、没有碎屑粒子。同样的盒子，mcraft.fun 加资源包就「像游戏」，现在像灰模演示。

### 5.4 和全方位路线图的品牌目标不冲突

[全方位路线图](./blocklegend-全方位优化分析与迭代路线图.md) 要求：不要再加深官方 MC 辨识度，品牌走「儿童向木框 + 符文金 + 声波蓝」。本文说的「换真像素图集」是**画质跃迁**，不是抄正版皮肤。图集可以用原创调色（木/金/蓝），只要是手绘 16×16、最近邻，不要继续用噪声填充。

## 6. 该做 / 不该做（调研结论）

**不要做**

- 接 Oasis / Genie / Marble 当世界
- 把 Meshy / 混元的 GLB 直接塞进 Three.js（和方块世界打架，平板更卡）
- 把「Make a Minecraft clone」整段丢给模型（参考 2 已写）
- 继续用「精致体素、倒角、软光」提示词出概念图

**值得做（按收益）**

1. **换真 16×16 图集**（最大一跳）。草/土/石/木/叶/沙先手绘或从开源像素包改成原创色，禁止 AI 直接当运行时贴图。
2. **生物保持盒模型**，按 Blockbench / 64×64 UV 画皮肤。`createFoxModel.js` 结构可留，只换材质。
3. 天空改成球体内贴，太阳方向 + 雾色。
4. 概念图提示词锁死「轴向盒子、无倒角、最近邻」。roster 图当配色板，不当建模目标。
5. 观感对照 [mcraft.fun](https://mcraft.fun) 的资源包，不要对照 Oasis 视频。

一句话：**X 上成功的是「AI 假装成我的世界」；你们要的是「网页里像成品体素游戏的英语课」。前者不能替换后者。美术下一刀砍图集质量，不砍生成模型。**
