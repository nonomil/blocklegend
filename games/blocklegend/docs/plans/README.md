## 执行规则

1. 纯逻辑进 `data/*.js` 或新 `data/quests.js`，`game.js` 只装配。
2. 先写失败测试，再写最少实现。验证命令：

```text
node --test --test-concurrency=1 tests/blocklegend.test.mjs
```

3. 不改词库 catalog、不改 workbench 存储 key、不整仓重写 `engine.js`。
4. 战斗链路的完成定义是“真实 Chrome 中世界不停 + V 命中生效 + 无麦克风可通关”，不能只凭纯函数或静态 DOM 测试标完成。
5. 每阶段验收见该阶段文件末尾。编码顺序：**Phase 5 验收/收口 → Phase 6**。不要回头做技能树或 Minecraft Gateway。

### 新附图的覆盖关系

- Phase 5 覆盖 Phase 1/2 中“普通怪首击弹题”“Boss 大题卡破盾”“快速挑战可暂停”等旧描述。
- `openQuiz` 继续服务词块、单词闸门和独立教学，不再作为普通战斗或语音失败的默认消费者。
- 常驻的是听写结果区域，不是常驻录音；浏览器只在玩家按 V 后请求一次识别。
- 参考图中的火/雷/冰技能栏、1万～10万传送价、整页家长报告不进入当前编码序列。
