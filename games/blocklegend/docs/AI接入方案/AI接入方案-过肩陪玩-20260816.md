## 1. 一句话

陪玩站在孩子肩膀后面：能看见主角在看什么、刚做了什么、周围有什么；用短英语提醒开口；按住 G 可以和它语音对话。没模型、没网，游戏照旧能打。

这比一般「AI 接入我的世界」更像真人联机。那些 NPC 只知道自己的坐标和聊天框；网页里准星、听写、蓝罩、商人都已经在 `game.js` 里，陪玩天生有上帝视角。

---

## 2. 陪玩是什么 / 不是什么

| 是 | 不是 |
|----|------|
| 过肩队友：看见主角行为 + 环境 | 会走路、挖矿、合成的第二个角色 |
| 提醒开口：`Look. Say lemon.` | 网页里的 ChatGPT 长聊 |
| 语音对话：孩子说英语，它用英语回 | 截屏给视觉模型认字（第一版不做） |
| 模板提醒保底，模型只是升级 | 搬 Minecraft-AI 的 Player2 / Gateway |
| 对白只留本机、本局 | 新 localStorage key、默认上传录音 |

孩子眼里：右上或准星旁一条气泡，像联机队友在说话。世界里可以以后再挂一个身体，脑子仍是这份事件流。

## 3. 三件能力

### 3.1 看见（事件流，不是截图）

每帧不必问模型。只在**事情变化**时打一份快照：

```text
look     准星：mob/boss/merchant/animal/word-block/gate/block
word     lemon / 柠檬
doing    look | swing | bolt | speak | type | walk-merchant | mine
heard    孩子刚被听写到的英文（已有引号）
nearby   附近怪种类、Boss 罩、商人是否在
learn    未跟读、连击、本关 focus 词
```

来源现成：`lookSubject()`、`session.boss`、`session.nearMerchant`、听写结果、五数。  
截 Canvas 给视觉模型是加分项，第一版不做。状态比像素更准。

### 3.2 提醒（主动喊，不打断战斗）

只在变化时出一句，冷却 ≥ 4 秒，最多 8 个词：

| 触发 | 陪玩说 |
|------|--------|
| 对准新怪，词牌出现 | `Look. Say lemon.` |
| 孩子砍但不念 | `Slow. Say the word.` |
| 听写对上 | `Yes! Big hit.` |
| 听写错 | `Again. Lemon.` |
| Boss 蓝罩 | `Shield. Say pardon.` |
| 罩破 | `Shield down. Hit!` |
| 走近商人 | `Press F. Talk to Leo.` |
| 未跟读连涨 | `Say it. Don't only click.` |

世界不停。提醒是旁白，不是弹窗。

### 3.3 语音对话（孩子和陪玩说话）

两路麦克风，不要抢：

| 键 | 谁在听 | 成功长什么样 |
|----|--------|----------------|
| **V** | 战斗开口（Phase 5） | 念准星词 → 暴击 / 碎罩 |
| **G** | 跟陪玩说话 | 孩子说英语 → 陪玩用英语回，并 TTS 读出来 |

规则：

- 按住 G 才听陪玩；松开就停。V 优先，G 期间按 V 立刻改听准星词。
- 陪玩听到的句子如果对上当前词牌，**同时算战斗成功**（说话也是打怪）。
- 陪玩只回短英语；中文最多半句提示，不把词义答案念满。
- 无 `SpeechRecognition`：G 聚焦一行打字，回车发送，仍 TTS 回复。
- 无模型：用模板回（`Say lemon.` / `I see the slime.` / `Try again.`）。
- 有模型：把快照 + 孩子刚说的话发给 OpenAI 兼容接口，只要一句英文。

浏览器已有 `webkitSpeechRecognition` 和 `speechSynthesis`。不训模型、不存录音。

---

## 4. 为什么比 Minecraft-AI 简单且更像联机

Minecraft-AI 要穿过 Forge + Player2 NPC + 本机 Gateway，NPC 眼睛是假的，只能靠聊天猜主角在干什么。

方块传奇：

```text
孩子操作
  → game.js 已有准星 / 听写 / 战斗状态
  → data/companion.js 决定：沉默 / 提醒 / 回答
  → 气泡 + speechSynthesis
  →（可选）本机或工作台已有的 OpenAI 兼容地址
```

只借三件事：短句、本机对白、模型挂了还能玩。  
不借：Player2、Forge、寻路采集、整站家长工作台、会走路的身体。

---

## 5. 无模型也能玩 / 有模型再升级

**L0 模板陪玩（必做）**  
`decideCue(snapshot)` 纯函数：输入快照，输出 `{ silent | remind | reply, text, say }`。单测不碰网络。

**L1 语音进出（必做）**  
提醒和回复走 TTS；G 走现有 `speech-input.js` 的 `matchHeard`。

**L2 模型陪玩（可选）**  
仅当本局能读到 endpoint（工作台已有配置或本局粘贴，**不新开 localStorage key**）。超时 2 秒就回落到 L0。不把录音、截图、API Key 写进仓库或 progress。

---

## 6. 隐私与存储

- 不新开 localStorage key。对白默认只在本局内存；若要留给家长，走现有 workbench 事件，不另造库。
- 不上传原始音频。上行最多：快照 JSON + 听写文本。
- 第一版不传截图。
- 模型失败：气泡写 `I'll watch. You can still play.`，战斗不受影响。

---

## 7. 和现有阶段的顺序

1. **Phase 5** 不停战开口（V、听写引号、砍怪不暂停）。没有这条，陪玩只能对着暂停题卡喊。
2. **Phase 6** 本方案：快照 → 模板提醒 → TTS → G 对话 → 可选模型。
3. 以后才考虑：世界里的伙伴模型、截图视觉、家长报告页。

热键合同不变：4 工具、Q 魔法、T 打字吟唱、F 商人。不改 `UNLOCK_COST`，不加火/雷/冰技能树。

## 8. 验收（孩子能感觉到联机）

- 对准史莱姆，几秒内陪玩说 `Say …`，画面不冻。
- 按 V 念对，陪玩说 `Yes!`，伤害变大或罩碎。
- 按住 G 说一句英语，陪玩用英语回，并读出来。
- 对陪玩说出当前词牌，怪掉血（对话也算开口）。
- 拔网、没 Key：提醒还在，战斗还能打。
- `node --test tests/blocklegend.test.mjs tests/world-games.test.mjs` 全绿。
