## 2. 明确不做什么（写进后续所有美术任务）

1. 不接 Oasis / Genie 3 / Marble 当世界，不跑 open-oasis 当运行时。
2. 不把 Meshy / Tripo / Rodin / Hunyuan3D / TRELLIS 的 GLB 直接进 `engine.js`。
3. 不把参考 2 的短提示或 docsbot 长提示整段丢给模型改本仓库。
4. 不重写 `engine.js` 合批/碰撞/世界生成；只换图集数据、UV、天空、材质。
5. 不再用「倒角、软光、高密度体素、PBR」出角色概念图。
6. 不把 Phase 4 变成技能树、1 万+ 传送价、整页家长报告（Phase 4 原文已禁）。
7. 平板 / Capacitor 美术适配仍按桌面优先，本方案不开工移动摇杆（除非产品点名 BL-20）。

## 3. 后续分刀（按可见收益）

北极星不变：看见英文、听见英文、说出或拼出英文。美术只服务「孩子一眼觉得这是成品游戏」，不服务「更像正版我的世界」。

### 刀 A — 真像素图集（本方案主刀，预计影响最大）

**目标：** 走进第一关平原，草/土/石/橡木立刻像「像素游戏」而不是「噪声演示」。

**做：**

1. 从 `makeBlockAtlas()` 抽出 `data/atlas-paint.js` 或静态 PNG 图集（推荐静态 PNG + 现有 UV 表，canvas 噪声降为缺图兜底）。
2. 先手绘或改开源像素块 **8 张**：草顶、草侧（泥+草沿）、泥、石、橡木侧、橡木顶、橡叶、沙。16×16，最近邻，`NearestFilter` 已有则保持。
3. 色盘用品牌色微调（草绿可偏暖、木偏橡木金），避免 1:1 复制官方贴图。
4. 叶子开 `alphaTest` 镂空（优化分析 §5.2 已写，顺手做）。
5. 验收：同一视角截图，换图集前后并排；不改任何玩法代码时世界明显更「块」。

**不改：** 区块合批、气候染色顶点色可以留（草顶仍可用顶点色乘气候，但底图必须是清晰像素，不能再是 10% 随机亮度噪声铺满）。

**验证：** 静态：图集 PNG 尺寸、格子数、UV 索引与 `tileIndex` 对得上。实机：Chrome 第一关截图。禁止只靠单元测试说「图集完成」。

### 刀 B — 概念图与盒模型对齐

**目标：** 再生图或改皮肤时，参考图和 `img2threejs` 盒子是同一种几何。

**做：**

1. 生图提示词锁定调研 §4.3（轴向盒子、无倒角、最近邻、T-pose）。
2. 现有 roster PNG 降级为配色板，不作为建模目标。
3. 每种怪一张 64×64（或 32×32）UV 皮肤，贴到现有 `BoxGeometry` 组；先做史莱姆、狐狸、僵尸、铁傀儡（孩子第一关就能看见）。
4. 第一关 HUD 文案仍按 BL-19 走原创名（漏字史莱姆等），皮肤可以像体素，名字不要写 WITHER。

**不改：** 再拆一套高密度体素网格；不引入蒙皮骨骼（行走仍用现有 Group + `sin(t)`）。

### 刀 C — 天空、光、碎屑（优化分析 §5.1 / §5.3，降为第二刀）

结构四件事已有，缺的是氛围：

1. 天空 PNG 贴到内面球体，随相机平移（现在 `scene.background` 转身穿帮）。
2. 定向光 + 现有顶点 AO，不要上真实阴影（WebView 红线）。
3. 挖掘命中点 4–8 个碎屑面片；三材质短音效走 `game-sfx.js`（BL-17 可与此合并）。
4. 可挖/不可挖目标框换色（白/红）。

`forest / quarry / astral` 三张天空：有关卡再用，无关卡先不补（优化分析缺陷 #8）。

### 刀 D — 生物动画（优化分析 §5.4）

盒模型 Group 已齐：行走摆动、受击闪白 100ms、死亡缩放。每种怪约 10 行。Boss 罩用半透明球 + 加色边缘，破罩变红。不新做网格。

### 刀 E — Phase 4 UI 品牌（BL-16～18，世界好看之后）

木框 9-slice、16px 图标换 Emoji、音量三开关、设置写入 `progress.settings`。概念图只抽语言，不贴 `ui-refs` 原图进运行时（除非切成九宫格）。
